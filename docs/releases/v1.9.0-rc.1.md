# FedGuardLab v1.9.0-rc.1

Release candidate readiness for v1.9.0 Experiment Result Management.

## Scope

v1.9.0-rc.1 does not add runtime features. It validates the v1.9 alpha and beta work as a release candidate.

Completed v1.9 scope includes:

- Dashboard history experiment management UI.
- Job archive / restore workflow.
- Archived job filtering and comparison protection.
- Comparison report history API and Dashboard panel.
- Unified report / artifact entry styling.
- Reports cleanup summary API and Dashboard panel.
- Reports cleanup run API with safe dry-run default.
- Dashboard cleanup run controls with explicit confirmation for real deletion.
- v1.9 alpha release documentation consolidation.
- v1.9 beta readiness documentation.

## Reports cleanup safety model

- `GET /reports/cleanup/summary` is read-only.
- `POST /reports/cleanup/run` defaults to `dry_run=true`.
- Real deletion requires `dry_run=false` and `confirm=true`.
- The Dashboard cleanup button requires browser confirmation before real deletion.
- Cleanup only acts on backend-generated cleanup preview candidates.
- Path safety checks reject reports root deletion and paths outside the reports root.

## Validation checklist

- `git diff --check`
- `python -m ruff check .`
- `python quick_test.py`
- `python -m pytest`
- `cd web && npm run build`
- `python api_smoke_test.py`
- `docker compose config`
- `docker compose build`
- `docker compose up -d`
- `python api_smoke_test.py --wait-finished --write-finished-job-id smoke_finished_job_id.txt`
- `docker compose restart backend`
- `python api_smoke_test.py --check-recovery <finished_job_id>`
- `docker compose down`

## Notes

This release candidate should not modify API behavior, training logic, report artifact URLs, Docker runtime, or dependencies.
