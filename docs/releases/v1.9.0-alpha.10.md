# FedGuardLab v1.9.0-alpha.10 Release Notes

## Focus

v1.9.0-alpha.10 is a documentation consolidation release for the v1.9.0 alpha series.

No runtime feature, API behavior, training logic, report artifact URL, Docker runtime, or dependency change is introduced in this release.

## v1.9.0 alpha series summary

v1.9.0 focuses on Experiment Result Management:

- Dashboard history experiment management.
- Job archive / restore flow.
- Archived / active / all job filtering.
- Comparison report history API and Dashboard listing.
- Dashboard CSS cleanup and report entry style unification.
- Reports cleanup summary API and Dashboard read-only panel.
- Reports cleanup run API with dry-run default and explicit confirmation for deletion.
- Dashboard cleanup run controls with preview, confirmation, and result feedback.

## Safety notes

Reports cleanup remains intentionally guarded:

- `GET /reports/cleanup/summary` is read-only.
- `POST /reports/cleanup/run` defaults to `dry_run=true`.
- Real deletion requires both `dry_run=false` and `confirm=true`.
- The backend only deletes candidates derived from cleanup preview.
- Path safety checks reject reports root deletion and paths outside the reports tree.
