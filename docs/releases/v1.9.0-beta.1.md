# FedGuardLab v1.9.0-beta.1

Status: Beta readiness validation for v1.9.0 Experiment Result Management.

## Scope

v1.9.0-beta.1 does not add runtime features, dependencies, API behavior changes, training logic changes, report artifact URL changes, or Docker runtime changes.

The goal is to validate the completed v1.9 alpha series and prepare the project for release-candidate hardening.

## Completed v1.9 alpha scope

- Dashboard history experiment management UI.
- Backend archive / restore support for jobs.
- Dashboard archive / restore controls.
- Comparison report history API.
- Dashboard comparison report history panel.
- Dashboard report entry styling unification.
- Reports cleanup summary API.
- Reports cleanup summary panel.
- Reports cleanup run API with dry-run default and explicit confirmation for deletion.
- Dashboard cleanup run controls.
- Consolidated alpha release documentation.

## Reports cleanup safety model

- `GET /reports/cleanup/summary` is read-only.
- `POST /reports/cleanup/run` defaults to `dry_run=true`.
- Real deletion requires `dry_run=false` and `confirm=true`.
- Cleanup only targets backend-generated preview candidates.
- Path safety checks reject reports root deletion and paths outside the reports root.
